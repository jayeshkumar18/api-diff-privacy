API Diff – Privacy Policy

Last updated: September 1, 2026

API Diff – Response Change Detector is a Chrome DevTools extension designed to help developers capture, compare, and review JSON API responses.

Data Collection

API Diff does not collect, transmit, sell, or share personal information. The extension processes API response data locally inside the user's browser.

Data Stored Locally

API Diff may store the following information using Chrome's local extension storage:

  • Captured API response history
  • Saved API baselines
  • Ignore-field rules
  • API comparison settings

This data remains on the user's device and is not sent to any external server.

Network Access

API Diff observes Fetch/XHR requests that are already visible inside Chrome DevTools. The extension does not create additional requests to external servers for analytics, tracking, advertising, or data collection.

Third-Party Services

API Diff does not use third-party analytics, advertising networks, tracking services, or cloud storage.

Data Sharing

API Diff does not sell or share user data with third parties. Users may manually copy or export API diff reports. Any exported data is controlled entirely by the user.

Data Removal

Users can remove stored API history directly from the extension using the Clear History feature.

Saved baselines and ignore-field rules can also be removed from within the extension.

Uninstalling the extension removes extension data according to Chrome's extension storage behavior.

Changes to This Privacy Policy

This privacy policy may be updated if API Diff adds features that change how data is handled.

Contact

For privacy-related questions regarding API Diff, contact the developer through the support information provided on the Chrome Web Store listing.
